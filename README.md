# **#Makuori - Handmade \& Hijab Online Store**

#### 

#### \##Project Idea



Makuori is an online store for handmade macramé products and hijabs.



Customers can browse products, view product details, add items to their cart, and place orders.



The system will also allow staff and administrators to manage products and orders according to their roles and permissions.



#### \## Technologies



\- React.js with TypeScript

\- FastAPI with Python

\- REST API

\- Authentication and Authorization

\- Role-Based Access Control (RBAC)

\- Database
